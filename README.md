# Grade 3 Science Adventure v0.2

A mission-based interactive game built from the Grade 3 Science Second Term question bank.

## Curriculum structure
The game follows the five Second Term topic areas in the current three-term Grade 3 Science coverage used for this project:
1. Living and Non-Living
2. Animal and Plant Parts
3. Basic Needs and Environment
4. Movement: Pushes, Pulls, and Causes
5. Position and Change in Position

## Game design
- 105-question bank retained from the tested v0.1 foundation
- 5 progressive missions
- 3 questions per mission per playthrough
- 3 lives per mission
- 100 points per correct answer
- Immediate rationale after every answer
- 1–3 stars per mission
- Mission unlock system
- Persistent local progress using browser localStorage
- Total score, correct answers, and stars
- Perfect-mission badges
- Responsive/mobile-friendly interface
- No Supabase and no login required

## Important
The question bank is not changed by this version. The game layer is upgraded around the existing bank so the tested content remains intact.
